#### Question 1

- A **node**  is a service/process that is registered with the ROS master that is called and ran
- A **publisher** is a part of a service that broadcasts information to a topic
- A **topic** is a live information chanel that gets updated by publishers
- A **Subscriber** reads designated topics where it then executes some callback function to handle the message
